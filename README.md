# Klokkijken

Oefenapps voor klokkijken in groep 5/6, met de vakkenmethode: **over**, **voor half**, **over half** en **voor**.

- `index.html` – startpagina om een app te kiezen
- `wijzerklok.html` – de wijzerklok in 5 stappen: minuten kiezen → minuten + uur (twee klokken) kiezen / typen → hele klok kiezen / typen
- `digitale-klok.html` – de digitale klok, minuten herkennen in 3 stappen: minuten → zeggen, zeggen → minuten, zelf typen

Losse HTML-bestanden zonder build-stap. Werkt op digibord, Chromebook en iPad. Instellingen (stap, hulpknoppen, geluid) worden per browser onthouden.

Online zetten: Settings → Pages → Deploy from branch → `main` / root.
